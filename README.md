# games

AI-assisted game projects.

| Project | Engine | Description |
|---|---|---|
| [apex](apex/) | Godot 4.5 | Predator roguelite. You're a young lion: hunt, grow strong, take a pride and hold it. About 15 minutes a run. |

Each project is self-contained. To play one, import its `project.godot` in Godot. To work on one with Claude Code, point the session at that project's folder so it picks up the project's `CLAUDE.md`.

See `NOTES.md` for the goal, the decision log, how we compare drafts, and ideas for the next ones.
